# v0.8 Operational Storytelling Contract

Each case opens with a concrete engineering question and a reason to watch. The Guided Story proceeds from observed measurements through SP03, SP04, Supervisor and independent Judge, finishing with an engineering deliverable containing findings, missing evidence and suggested follow-up. Agent Flow explains *how* the record was produced, rather than introducing an unrelated technology showpiece.

## Three scenario propositions

- RAN-01: Near-total packet loss -> qualified radio/protocol observations -> time-aligned radio and flow mapping needed.
- RAN-02: Sender/receiver throughput disparity despite low receiver-reported packet loss -> accurate metric interpretation -> bearer and aligned flow verification needed.
- RAN-03: Seven zero-reception intervals -> observed interruption and possible radio indicators -> temporal/UE mapping needed.

The demo uses recorded synthetic evidence and is not live inference, independently verified RCA accuracy, remediation, recovery, an acceptance decision, or proven operator savings. Streamlit playback pacing does not represent original execution speed.
